# Tài liệu Dự án MPT MacusaOne

Chào mừng bạn đến với hệ thống quản trị MPT MacusaOne. Tài liệu được chia thành các phần sau để dễ dàng tra cứu:

## 📂 Danh mục tài liệu

### 1. [Quản trị Người dùng & Phân quyền](user-management.md)
*   Quản lý User, Role, Permission.
*   Trang Profile cá nhân.
*   Nhật ký đăng nhập và bảo mật tài khoản.

### 2. [Quản lý VPS](docs/vps-management.md): Theo dõi trạng thái, tự động cảnh báo và kiểm tra kết nối VPS.
- [Quản lý Domain](docs/domain-management.md): Tích hợp Namecheap API, quản lý Subdomain và tự động tính toán giới hạn DNS.
- [Giám sát & Thông báo](docs/monitoring.md): Hệ thống thông báo thời gian thực qua Database Notifications.
*   Lịch sử thay đổi dữ liệu VPS.

### 3. [Giám sát & Thống kê](monitoring.md)
*   Hệ thống quét trạng thái tự động 5 phút/lần.
*   Cảnh báo mất kết nối qua chuông thông báo.
*   Widget thống kê trên Dashboard.

### 4. [Review & Đề xuất Cải tiến](review_and_suggestions.md)
*   Đánh giá chất lượng code hiện tại.
*   Lộ trình phát triển các tính năng tiếp theo.

---
*Hệ thống được phát triển trên nền tảng Laravel 12 & Filament v5.*
